# Yatori 配置与操作

源码仓库：[zrmugua/chaoxing](https://github.com/zrmugua/chaoxing)。本平台使用固定版本 Yatori Go 核心访问学习通，Vue 控制台负责配置与任务管理。

## 使用流程

1. 在账号管理中添加学习通账号，点击「登录验证」，等待课程同步完成。
2. 点击该账号的「配置与启动」，选择全部课程、仅学习所选课程或排除课程。可以从已同步课程中多选，也可以输入完整课程名或课程编号。
3. 选择视频模式、答题方式、提交策略，以及章测、作业、考试范围。账号独立保存配置，也可以使用系统全局规则。
4. 点击「保存并准备启动」，查看课程名单和配置摘要，再点击「开始运行」。课程页的单课程和批量任务使用相同启动摘要。
5. 在任务中心、运行记录和系统日志中查看结果。保存答案、交卷请求和服务端完成确认分别记录；需要人工验证时，在学习通处理后同步状态。

任务会保存创建时的课程规则。账号凭据、会话、通知邮箱和代理授权加密持久化，每个原生执行进程拥有独立 Yatori 缓存。

### 配置生效范围

「系统设置 → 默认学习配置」为新账号及跟随默认配置的账号提供学习规则。账号在「配置与启动」中保存后，使用整套账号专属规则；点击「跟随默认配置」可恢复使用系统默认规则。修改默认配置后，跟随默认配置的账号在创建新任务时使用更新后的规则；已有任务继续使用创建时的规则。

系统设置还集中管理所有账号共用的任务并发、重试、日志、AI 接口、题库服务和邮件发送服务。账号配置选择答题方式、课程范围与提交策略，并可单独设置通知邮箱和网络代理；账号通知邮箱留空时使用系统收件人。

课程管理按列表展示课程名称、编号、所属账号、教师与最近同步时间，可搜索或按账号筛选，并在每行查看章节、同步和创建学习任务。

### 账号运行日志

运行日志默认展示 Yatori 实际写入控制台的原文，支持选择学习通账号、任务、日志来源和级别，并可搜索、暂停更新及导出当前筛选结果。账号管理中的「日志」可直接打开该账号的记录。

Yatori 的标准输出、标准错误及 Go 标准日志通过账号独立进程回传，标记为「Yatori」；调度、重试及任务结果由管理台记录，标记为「管理台」。日志保留原文中的时间和错误信息，移除终端颜色控制码并过滤密码、Cookie 和令牌。日志级别遵循系统设置。

更新后运行账号任务时开始采集原始输出。单行超过 64 KiB 时保留前段并标记截断；网页保留最近 2,000 条已加载记录。数据库升级会保留历史管理台日志，可通过来源筛选查看。

## 与原版生成器对应

| 原版配置 | 控制台入口和行为 |
| --- | --- |
| `videoModel` 0 / 1 / 2 / 3 | 视频关闭、普通、多课程、多任务点模式 |
| `cxNode` | 多任务点数量 1–7；调度器为每个点分配独立执行进程，合计最多 8 个 |
| `autoExam` 0 / 1 / 2 / 3 | 关闭、外部 AI、外置题库、学习通内置 AI |
| `examAutoSubmit` 0 / 1 / 2 | 只保存、直接交卷、无空题交卷；第三种来自 Android App |
| `cxChapterTestSw` / `cxWorkSw` / `cxExamSw` | 独立控制章测、作业和考试答题 |
| `includeCourses` / `excludeCourses` | 包含 / 排除课程名称或编号；排除优先 |
| `shuffleSw` | 随机排列课程、章节与任务点 |
| `remarkName` | 账号名称 |
| `informEmails` | 账号通知邮箱，留空使用系统收件人 |
| `isProxy` | 账号通知与网络中设置 HTTP / HTTPS 代理地址，支持代理授权 |
| `aiSetting` | 系统设置 → 运行与 AI；服务预设、模型、密钥和协议 |
| `apiQueSetting.url` | 系统设置 → 题库；Yatori 自定义协议、Token、AI 回退、本机 / 局域网接口 |
| `emailInform` | SMTP SSL / STARTTLS、发件人、授权与收件人 |
| `completionTone` | 浏览器完成提示音；页面打开且浏览器允许播放音频时生效 |
| `colorLog` | 日志颜色分级 |
| `logOutFileSw` | 数据目录 `console.log`；单文件约 1 MB，轮换保留 3 份 |
| `logLevel` | DEBUG / INFO / WARNING / ERROR，数据库与文本日志使用同一阈值 |
| `config.yml` 导入 / 导出 | 账号管理或系统设置 → 配置文件 |

音频、文档、阅读、外链、上报客户端、执行时限、重试与并发预算由控制台补充配置。视频/音频按实际经过时间推进，恢复时使用服务端播放位置。

## 答题与恢复

章测表单参考固定版 `XueXiTongChapterTestApi.WorkNewSubmitAnswer` 协议；作业和考试复用 Yatori 的入口、试卷、逐题读取和提交 API。试卷隐藏字段保留在本账号原生进程中，管理 API 返回题目与状态。支持可明确解析的单选、多选、判断、填空、简答和论述题。

答案按选项原文或明确字母映射，判断与填空按题型检查。不确定、缺项或未支持的题型保留空题。只保存模式保留试卷待交卷状态；无空题模式在答案完整时请求交卷，否则保存已匹配答案。章测保存会保留未覆盖题目的现有表单值。

打开考试可能启动平台计时。任务在打开试卷与发送答案前写入检查点；请求结果不明时回读平台状态，保留待确认状态。已获保存响应的试卷在同一任务恢复时继续等待交卷或确认。课程/试卷不会仅因接口请求成功而被标记为服务端完成。

验证码、人脸、访问限制、重考/重做入口、未知表单或缺失签名字段进入人工处理或兼容性错误状态。考试倒计时按学习通规则继续，暂停本地任务不会暂停考试计时。

当前没有真实学习通账号与外部服务授权。解析、保存、交卷及恢复已使用离线协议响应验证；真实章测、作业、考试和学习通 AI 仍需按目标学校、课程验收。

## YAML 配置

支持原版生成器的 `setting` / `users` 学习通配置，导入时按账号匹配更新，新增账号自动创建。先完成全部校验，再在事务内加密保存；正在执行任务时须先暂停。导入后重新验证账号并同步课程。

默认导出省略账号密码、密钥与代理授权，适合同一实例恢复配置。迁往另一实例时，可主动勾选「包含账号密码和服务密钥」，下载文件需安全保管。`console` 扩展字段保存上报客户端、执行时限等控制台配置，供本平台往返使用。

平台面向学习通，导入其他平台账号会提示格式不符合要求。原版 `isProxy=1` 配置需具有本平台保存的账号代理地址，或 `console.proxyUrl`。题库提供方使用 `CUSTOM` 协议；其他提供方应通过兼容服务接入。

## AI 与题库

AI 支持 Chat Completions、Responses 和秘塔协议。预设包括 OpenAI、DeepSeek、通义千问、智谱、星火、豆包、硅基流动与秘塔；模型名称和授权需由服务提供方确认。

自定义题库接收 POST JSON：

```json
{"md5":"md5(type + content)","type":"单选题","content":"题目正文","options":["选项一","选项二"],"answers":[]}
```

响应接受根对象、`question` 或 `data` 中的 `answer` 字符串或 `answers` 字符串数组。可选 `code` 为 0、1 或 200。Token 按需放入 Bearer 授权头。默认使用公共 HTTPS；开启局域网接口后，可连接本机或私网 HTTP 题库。题目与选项发送到已选择的答案服务。
