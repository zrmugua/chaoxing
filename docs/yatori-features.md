# 配置与操作

在账号页完成登录验证和课程同步，然后进入「配置与启动」。课程页以列表展示课程名称、账号、教师、编号与同步时间，支持搜索和账号筛选。

## 系统设置与账号配置

系统默认学习规则用于跟随默认配置的账号。账号保存独立配置后使用整套账号规则；点击「跟随默认配置」恢复继承。新任务保存学习规则快照。系统还提供共用 AI、题库、SMTP、日志及账号并发设置；账号可配置通知邮箱和 HTTP 代理。

| 控制项 | 原版字段与行为 |
| --- | --- |
| 视频模式 | `videoModel` 0/1/2/3；关闭、普通、多课程、多任务点 |
| 同时任务点 | `cxNode`；由 Console 在进程内调度 |
| 章测、作业、考试 | `cxChapterTestSw`、`cxWorkSw`、`cxExamSw` |
| 随机顺序 | `shuffleSw` |
| 答题模式 | `autoExam` 0/1/2/3；关闭、外部 AI、题库、学习通 AI |
| 保存/交卷 | `examAutoSubmit` 0 保存，1 自动交卷，2 对章测检查空题，作业/考试自动交卷 |
| 课程范围 | App 将所选课程转成完整名称写入 `includeCourses` |
| AI、题库、邮件 | 写入原版 `setting` 对应字段 |

音频、文档、阅读、外链跟随原版流程；视频模式关闭时也会影响原版文档和外链处理。原版按名称筛选，同名课程需要同时选择。AI 使用 Chat Completions 兼容服务或秘塔，题库地址需符合原版协议。

## 账号日志

日志默认显示 Console 实际 stdout / stderr。可按学习通账号、任务、来源和级别筛选、搜索及导出。账号页「日志」直接打开对应账号。程序输出标记为「Yatori」，队列与进程状态标记为「管理台」。日志过滤密码、Cookie、令牌和终端控制码。Console 原始输出完整入库；Console 使用 INFO / DEBUG 模式，管理台的警告/错误筛选只作用于管理日志。

「执行结束」表示 Console 已退出。同步课程、章节与作业/考试可更新平台状态。暂停会结束进程，继续时重新启动 Console。服务停止后运行中的任务暂停；旧版本任务在升级时停止，重新启动前应核对配置。

## 配置文件

支持 Yatori YAML 导入导出，账号凭据和服务密钥加密保存。导出可选择包含密钥，需妥善保管文件。实际运行由管理服务生成单账号 `config.yaml`；进程退出后清理该明文临时文件。
