- 原版 Console 的 45 个运行文件通过固定提交哈希校验；Android 资源适配输入和三份模型通过独立哈希校验。

- Python 测试：111 项通过，1 项本机 Java 工具路径检查跳过；Gradle 的 3 项 Java 单元测试通过。
- Android 31 x86_64 模拟器覆盖安装通过；管理员登录、加密账号存储、Worker 心跳、服务停止与重启通过。
- 在 App UID 下，两份账号工作目录均从共享目录成功解析全部三份模型，ONNX 初始化正常。原版主程序输出与进程停止测试通过。

- 三个签名 APK 的应用 ID、版本、最低 Android 版本、ABI、原生程序、Python 源码、网页和许可证与构建输入一致；模型只打包一份，模型字节与原版一致。
