# 0.7.3 验证记录

日期：2026-10-22。Android 版本 0.7.3 / versionCode 17。

## 账号会话与课程查询

每次查询在原版 Console 登录后先读取课程列表，初始化账号编号。章节和作业/考试查询按课程编号、班级编号匹配本次返回的课程，使用最新 CPI。课程失效或初始化失败时终止查询，保留已有进度与同步时间。编号缺失、格式异常与整数越界分别返回具体提示。

每门课程通过自己的按钮更新章节进度；「同步课程列表」读取账号课程列表。查询沿用每批最多 100 个章节的完整性校验。原版 Console 主程序与学习业务源码通过固定来源校验。

## 验证结果

- Android 31 x86_64 模拟器上 12 组 Go 回归测试通过：覆盖新登录的空账号编号、连续两次查询、最新课程参数、课程与班级匹配、初始化失败、编号检查，以及章节元数据、异常响应和批次完整性。
- 登录测试调用原版 Cookie 登录；课程、章节和作业/考试调用边界使用合成数据，校验初始化顺序与传入的账号和课程编号。6 组章节解析测试同时在 Windows 通过。
- Python 进程与账号生命周期测试 37 项通过，2 项 POSIX 专用测试在 Windows 跳过。覆盖原始日志脱敏、查询错误传递、已有进度保留及账号学习状态。
- 网页生产构建、三种架构 Console 构建与 3 项 Java 单元测试通过。
- Android 安装和运行集成测试通过，覆盖模型解析、账号配置与选课持久化、进程停止及服务重启。
- 三个签名 APK 的架构、源码、网页、模型和原生程序与构建输入一致；v2/v3 签名及 16 KiB 对齐验证通过，证书与上一版本一致。

通用 APK 为 81.33 MiB，ARM64 为 59.01 MiB，ARM32 为 58.70 MiB。
