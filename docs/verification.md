# 0.7.2 验证记录

日期：2026-10-21。Android 版本 0.7.2 / versionCode 16。

## 章节进度查询

- 章节响应分别解析说明字段与章节数据，支持带字符串 `msg` 的有效响应、数值或字符串计数及 `data` 包装。
- 每批最多请求 100 个章节。平台拒绝、计数无效或缺少请求章节时终止本次更新，保留上次进度及同步时间。
- 查询失败的原因通过结构化结果返回，经过凭据脱敏后显示在课程行；原始 stdout / stderr 持续保留。
- 原版 Console 主程序与学习业务文件通过固定来源校验。修改位于查询入口、解析器与管理服务结果处理。

## 验证结果

6 组 Go 回归测试在 Windows 与 Android 31 x86_64 模拟器通过，包括有效元数据、平台错误提示、15 类异常响应、完成判定、205 章分批查询与中途失败时的整体回退。

Python 进程与账号生命周期测试 37 项通过、2 项 POSIX 专用测试在 Windows 跳过。真实子进程测试验证非零退出时保留错误原因、敏感字段脱敏及查询失败后的数据库进度保留。

网页生产构建、三种架构 Console 构建及 3 项 Java 单元测试通过。Android 31 x86_64 模拟器覆盖安装与运行集成测试通过，包括共享模型解析、账号配置持久化、进程停止及服务重启。三个 APK 的签名、对齐、源码、网页、模型和原生程序已与构建输入核对。

通用 APK 为 81.33 MiB，ARM64 为 59.02 MiB，ARM32 为 58.70 MiB。

## 验证范围

测试使用合成响应与隔离数据，真实学习通账号和目标 ARM 设备尚未连接验证。平台响应中的具体错误原因以账号实际查询为准。
