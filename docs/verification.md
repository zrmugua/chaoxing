# 0.7.5 验证记录

日期：2026-10-25。Android 版本 0.7.5 / versionCode 19。

## Console 日志时区

Android 在每次启动 Console 时通过 Java 系统接口读取当前时区名称和 UTC 偏移，传给独立子进程。查询桥接在原版主程序开始前设置 Go 本地时区，使新的原始日志按设备启动时的时区生成。北京时间设备使用 `Asia/Shanghai`（UTC+8）。

网页左侧采集时间继续按浏览器时区显示，数据库中的 Unix 时间戳与历史日志正文保留原值。设备时区调整后，新启动的进程会读取最新值。

## 验证结果

- Python 进程与 Android 边界测试共 33 项通过，2 项 POSIX 专用测试在 Windows 跳过。Java/Python 加密互操作在配置 JDK 后独立通过。
- Android 31 x86_64 模拟器上的 14 组 Go 测试通过，新增 UTC+8、UTC−5、UTC+5:45 与无效配置测试；验证格式化时间和 Unix 时间戳的一致性。
- Android 安装运行集成测试通过。实际打包的原生程序分别返回 UTC+8 与 UTC−5 的预期时区信息，并验证从 Android Java 读取的设备时区能够传到原生程序；共享模型、账号状态、进程停止和服务重启验证通过。
- 网页生产构建、三种架构 Console 构建与 3 项 Java 单元测试通过。
- 三个 APK 的架构、管理后端、网页、原生程序和模型与构建输入一致；v2/v3 签名及 16 KiB 对齐通过，证书与上一版本一致。

通用 APK 为 81.33 MiB，ARM64 为 59.02 MiB，ARM32 为 58.70 MiB。

## 章节卡片排查范围

源码核对显示，原版解析器在无法匹配 `window.AttachmentSetting` 且无法提取页面提示时返回“章节卡片缺少 AttachmentSetting”。卡片请求缺少 HTTP 状态校验，读取响应失败也可能被归为缺少配置。具体账号在不同章节随机报错的根因仍需发生时的实际响应确定；本次验证使用合成数据，未连接真实学习通账号和目标 ARM 设备。

升级前停止服务，同签名 APK 覆盖安装后重新启动。新日志使用进程启动时的设备时区；此前版本验证见 [0.7.4](history/verification-0.7.4.md)。
