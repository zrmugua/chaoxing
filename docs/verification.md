# 0.7.1 验证记录

日期：2026-10-21。Android 版本 0.7.1 / versionCode 15。

## 首页与账号配置

首页为统计页，展示任务总数、当前执行数量、账号数、课程数、状态分布、最近执行和后台心跳。导航提供「首页统计」，账号列表与详情页均提供「账号学习配置」。

- Vue 类型检查、生产构建与许可证生成通过。
- 账号学习配置与生命周期相关后端回归测试：45 项通过，包含单课程查询范围、失败重试、保留其他课程进度、列表同步范围和学习恢复。
- 隔离演示环境验证：首页默认路由、统计内容、两个账号配置入口、专属配置保存后重新打开、另一账号继续跟随默认配置、关闭抽屉时清理地址参数。
- 桌面与手机宽度检查导航、账号配置入口、单课程刷新按钮和表单布局。

## Android 与交付

原版 Console 来源校验、三种架构构建与共享 OCR 模型校验通过。3 项 Java 单元测试通过。三个 APK 的版本、架构、Python 源码、网页、原生程序、模型及许可证已核对，既有证书 v2/v3 签名与 16 KiB 原生库对齐校验通过。

通用 APK 为 81.32 MiB，ARM64 为 59.01 MiB，ARM32 为 58.70 MiB。

本次调整首页导航、配置入口与按课程刷新进度。真实学习通账号、课程和目标 ARM 设备尚未连接验证；既有运行验证见 [0.7.0](history/verification-0.7.0.md)。
