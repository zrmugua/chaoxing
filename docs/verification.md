# 0.5.3 验证记录

日期：2026-10-21。Android 版本为 0.5.3 / versionCode 10。本次更新调整章节测验和网络响应的验证识别，并在任务错误中提供具体原因。

## 测验读取与错误提示

- Go 测试通过。新增样本通过 Yatori `WorkFetchQuestion` 和实际请求适配入口读取章节测验，覆盖题目页中的普通验证码标识、脚本提示、隐藏验证控件和题目正文中的验证用语；读取成功并保留表单字段。
- 实际验证码输入、人脸验证标志、当前验证提示、试卷时效、考试须知和 HTTP 403 / 429 等情况仍返回对应原因。RPC 回归用例验证章节锁定原因可传至调用方。
- Python 3.12 与 Python 3.11 / Android 依赖环境各 95 项测试通过。新增用例验证验证码、人脸识别、访问频率、考试须知和未知原因的错误文案，并保留第几张任务卡的定位信息。
- TypeScript 检查及 Vite 生产构建通过。Yatori 固定提交及 45 个文件的源码清单校验通过。

## 验证范围与更新

测试使用本地 HTML / JSON 样本和模拟网络响应，验证 Yatori 核心 API、Go 适配层及 Python 错误展示的调用链。尚未连接安卓设备或真实学习通账号，用户课程的实际返回页面及覆盖安装后的运行仍需实机验证。
