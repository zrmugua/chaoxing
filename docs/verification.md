# 0.7.4 验证记录

日期：2026-10-23。Android 版本 0.7.4 / versionCode 18。

## AI 接口地址

生成 Console 私有运行配置和导出 YAML 时，服务域名及以 `/v1` 等数字版本号结尾的基础地址会补齐 `/chat/completions`。例如 `https://ai.example/v1` 会生成 `https://ai.example/v1/chat/completions`。完整 Chat Completions 地址规范化尾部斜杠，其他完整自定义路径保持原值。

网页 AI 设置提供填写说明。保存后暂停并继续账号，新进程使用最新地址。原有密钥加密、公开配置脱敏与私有运行文件清理继续生效。

## 验证结果

- Python 相关测试 77 项通过，2 项 POSIX 专用测试在 Windows 跳过。新增 17 项地址测试覆盖 8 个预设服务、尾部斜杠、完整接口地址、未启用配置和保存后的运行配置。
- 使用真实隔离子进程读回私有 YAML，确认 Console 的 `aiUrl` 为完整接口地址；导出 YAML 与预览请求使用同一目标地址，保留保存的基础地址。预览请求通过 HTTP MockTransport 校验 POST 路径和消息格式。
- Android 31 x86_64 模拟器上的 12 组 Go 章节与查询会话回归测试通过。
- 网页生产构建、三种架构 Console 构建与 3 项 Java 单元测试通过。Android 安装与运行集成测试通过，覆盖共享模型、账号配置持久化、进程停止与服务重启。
- 原版 Console 源码通过固定来源校验。三个 APK 的源码、网页、原生程序、模型、架构、签名和 16 KiB 对齐与构建输入核对通过。

通用 APK 为 81.33 MiB，ARM64 为 59.02 MiB，ARM32 为 58.70 MiB，签名证书与上一版本一致。
