# 0.5.2 验证记录

日期：2026-10-20。Android 版本为 0.5.2 / versionCode 9。此次更新接入 Yatori 控制台原文，并按学习通账号、任务与来源筛选日志。

## 日志与兼容性

- Go 测试通过，覆盖标准输出、标准错误、Go 标准日志和 Yatori 日志工具的原文采集，操作返回前的输出排空、超长行后续记录，以及日志事件与 RPC 响应的独立编码。
- Windows Python 3.12 与 Python 3.11 / Android 依赖环境各 90 项测试通过。新增用例覆盖日志事件、脱敏、RPC 返回值、账号与来源筛选、增量游标、任务账号绑定及旧数据库升级；回归验证短 Cookie 标志不会改变日志时间和数字，并过滤请求 URL 中的签名参数。
- TypeScript 检查、Vite 生产构建、Prettier 格式检查与 Git 差异检查通过。
- 使用本地独立数据库和样例账号验证：账号筛选后仅显示该账号记录，切换来源可查看 Yatori 或管理台日志，搜索原始响应正常。
- 浏览器检查桌面与 390 像素手机布局，原始文本、来源、账号和任务标记可读。页面截图使用样例数据。
