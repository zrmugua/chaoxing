# 0.5.1 验证记录

日期：2026-10-20。Android 版本为 0.5.1 / versionCode 8。本次更新包含课程列表布局，以及默认学习配置和账号专属配置的生效说明。Yatori 核心及 Android 服务代码沿用 0.5.0。

## 界面与规则

- TypeScript 检查与 Vite 生产构建通过，Prettier 格式检查和 Git 差异检查通过。
- 现有账号规则继承、独立配置、恢复默认及任务配置快照的 2 项 Python 测试通过。
- 使用独立临时数据库和本地样例账号，验证课程搜索、搜索空状态、账号筛选、章节抽屉、单课程与账号批量任务确认入口。
- 样例账号保存配置后显示「账号专属」，点击「跟随默认配置」后恢复继承；提示文字与 API 状态一致。
- 浏览器检查 1440 像素桌面布局及 390 像素手机布局，手机可横向查看课程列表的全部列和操作。

## Android 构建与包内容

- `:app:assembleDeviceRelease` 与 `:app:testDeviceReleaseUnitTest` 构建成功，3 项 Java Fernet 单元测试通过。
- 设备 APK 支持 ARM32 / ARM64，最低 Android 8 / API 26。
- 官方 apksigner 验证 v2 / v3 签名通过，签名证书与 0.5.0 一致。zipalign 检查通过。
- APK 内 27 个网页文件与本次前端构建逐字节一致，包含课程列表及默认配置说明；24 个 Python 源文件与当前源码一致。
- 核对两种 ARM 架构的 Go 原生库与 0.5.0 一致，并核对包内主要许可文本。
- APK 大小为 51,491,807 字节。
