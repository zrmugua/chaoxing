# 0.7.0 验证记录

日期：2026-10-21。Android 版本 0.7.0 / versionCode 14。

## 账号学习管理

- 后端测试 130 项通过、3 项按环境跳过。新增 19 项账号生命周期用例覆盖持久选课、并发版本校验、连续修改合并、旧进程回收、查询中断与恢复、查询失败、升级迁移、服务重启和规则快照。
- 平台章节进度保留实际同步结果与时间；Console 退出不会将课程进度设为完成。活动课程只根据原始课程活动日志展示。
- 课程从平台移除后保留历史，暂停失效清单并提示重新选择。运行记录支持按账号筛选。
- Vue 类型检查、生产构建和许可证生成通过。使用实际 Vue 响应式状态验证编辑期间轮询、版本冲突、明确重试、账号切换和销毁清理。
- 浏览器使用隔离演示账号和模拟 Console 输出验证课程选择、学习启动、运行中更换课程、同步进度后恢复、暂停及手机和桌面布局。演示验证未向学习通发送学习请求。

## Android

- 原版 Console 的 45 个运行文件通过固定提交哈希校验。ARM32、ARM64、x86_64 构建成功，原版 OCR 模型和资源适配输入通过哈希校验。
- 3 项 Java 单元测试通过。
- Android 31 x86_64 模拟器覆盖安装与集成测试通过：账号凭据加密、账号课程隔离、持久选择、过期版本拒绝、暂停/继续/停止和服务重启。
- 模拟器在 App UID 下运行原版程序并解析三份共享 OCR 模型；验证原始输出、子进程停止，以及父进程退出后由子进程保留的账号目录锁。目录交接完成后才能启动下一进程。
- 三个 APK 的应用 ID、版本、最低系统版本、ABI、Python 源码、网页、原生程序、模型和许可证与构建输入一致。同一发布证书的 v2/v3 签名及 16 KiB 原生库对齐校验通过。

## 验证范围与升级

Windows 测试跳过一项本机 Java 路径检查和两项 POSIX 专用进程测试；Java 与目录锁对应行为已在 Gradle / Android 模拟器验证。目标 ARM 真机与真实学习通账号、课程尚未连接验证。

停止服务后使用同签名 APK 覆盖安装，再启动服务。账号、课程、配置、历史和日志保留；已有活动学习记录的选课迁移为账号清单。进入账号核对选择后点击继续。
